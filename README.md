# Revenge Plugins

Plugins for [Revenge](https://revenge.palmdevs.me/), the Discord Android client mod.

## Install

In Revenge, go to **Settings → Plugins → Repositories → Add repository** and enter:

```
https://ghostixs.github.io/revenge-plugins
```

Then install plugins from **Browse Plugins**.

## Plugins

- **Notification List** — lists every channel with unread messages; tap a row to jump straight to that channel/message.
